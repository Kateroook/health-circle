Політика конфіденційності

Про застосунок Політика конфіденційності Підтримка Управління

HealthCircle поважає вашу конфіденційність та прагне захищати персональні дані користувачів. Ми збираємо лише мінімальний обсяг інформації, необхідний для забезпечення роботи застосунку.

Які дані ми збираємо

Ми можемо збирати наступні типи даних:

1. Особисті дані

Email-адреса та номер телефону — використовується для створення облікового запису та автентифікації користувача.

2. Дані про геолокацію

Місцезнаходження — використовується для передачі вашого статусу безпеки та геолокації обраним контактам (родині та друзям).

3. Дані про пристрій та технічна інформація

Ми можемо збирати обмежену технічну інформацію про пристрій, включаючи:

  • User agent дані (наприклад, операційна система, тип пристрою, клієнтська бібліотека)
  • Інформацію про пристрій (назва ОС, модель пристрою, платформа)

Приклад:
OS: Android
Client: OkHttp

Ці дані використовуються для забезпечення роботи застосунку, діагностики помилок та покращення продуктивності.

4. Дані для push-сповіщень

Firebase Cloud Messaging (FCM) токен — унікальний ідентифікатор пристрою, який використовується виключно для надсилання push-сповіщень.

5. Дані про використання застосунку

Дані використання — збираються для розуміння взаємодії користувачів із застосунком та покращення функціональності.

6. Логи дій користувача

Ми можемо логувати базові дії користувача, такі як:

  • створення облікового запису
  • вхід та вихід з акаунту
  • невдалі спроби входу
  • зміни в акаунті
  • відновлення паролю

Ці дані використовуються для забезпечення безпеки, діагностики та покращення користувацького досвіду.

7. Аналітика

Ми використовуємо Firebase Analytics для збору агрегованих та анонімізованих даних про використання застосунку.

Це допомагає нам:

  • розуміти поведінку користувачів
  • покращувати продуктивність застосунку
  • оптимізувати функціонал

Firebase Analytics не використовується для відстеження користувачів між сторонніми застосунками. Ми не використовуємо технології відстеження для відстеження між додатками.

Як ми використовуємо дані

Зібрані дані використовуються виключно для:

  • забезпечення роботи застосунку
  • взаємодії між користувачами
  • надсилання сповіщень про безпеку
  • покращення стабільності та продуктивності
  • аналітики та розвитку продукту

Передача даних

Ми не продаємо і не передаємо персональні дані третім сторонам.

Деякі дані можуть оброблятися довіреними сервісами, такими як: Google Firebase (аналітика та push-сповіщення).

Захист даних

Ми використовуємо сучасні методи захисту даних, включаючи шифрування з’єднання (HTTPS), для забезпечення безпеки інформації користувачів.

Ваші права

Ви можете у будь-який момент видалити свій обліковий запис разом із пов’язаними даними через функціонал застосунку.
